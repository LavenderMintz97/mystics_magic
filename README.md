# Mystics Magic

Static source for the Mystics Magic website deployed at <https://mystics-magic.pages.dev/>.

## Structure

- `site/` — production-ready HTML, CSS, images, metadata, and Cloudflare Pages files.
- `tests/` — content and design-regression checks.
- `scripts/build.mjs` — copies the checked source into `dist/`.

## Development

Serve `site/` with any local static server, or run:

```bash
npm run build
npm run preview
```

## Verification

```bash
npm test
npm run build
```

## Cloudflare Pages

The build command is `npm run build` and the output directory is `dist/`.

```bash
npm run deploy
```

Reading services use the published USD tiers and service-specific Telegram pathways. Digital products are temporarily unavailable and have no active purchase links.
